- Use Java only. Target the JDK version declared in `pom.xml`.
- The entrypoint (`public static void main`) stays in `src/main/java/powerband/Main.java`.
- Instruments (Bridge abstraction) stay in `src/main/java/powerband/instrument/`.
- Synth commands (Bridge implementation) stay in `src/main/java/powerband/synth/`.
- Business logic stays in `src/main/java/powerband/service/`.
- Data access (binary files, index, sorting, search) stays in `src/main/java/powerband/repository/`.
- Input and output types (DTOs) stay in `src/main/java/powerband/dto/`.
- Custom exceptions stay in `src/main/java/powerband/exception/` and extend `PowerBandException`.
- Packages are lowercase; classes are `PascalCase`; methods and fields are `camelCase`; constants are `UPPER_SNAKE_CASE`.
- One public top-level type per file, and the file name matches the type name.
- Depend on interfaces for services and repositories; keep fields `private` and expose behavior through methods.
- Prefer the standard library. Add a dependency only when the standard library cannot do the job.
- Constants are declared in `src/main/java/powerband/util/IConstants.java`, as `public static final` fields of an interface. No hardcoded values elsewhere.
- Every method parameter name starts with `p` followed by a descriptive name (e.g., `pName`, `pNote`, `pEvent`).
- Close every stream and file with try-with-resources. Never swallow an `IOException`: wrap it in a custom exception with a clear message.
- Never sort or traverse in-memory arrays of indexed recordings: the index is sorted and searched on disk.
